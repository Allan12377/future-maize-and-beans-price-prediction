# Future Maize and Beans Price Prediction

**Course:** BCS 3101 Basics of Machine Learning  
 Kabale University  
**Year:** 3 Semester 1  

## Project Goal
Predict the monthly retail price (UGX per kg) of maize and of beans in Ugandan markets using historical World Food Programme price data.

## Folder Structure
- `data/raw/` – original WFP CSV files (not changed)
- `data/processed/` – cleaned tables produced by the notebooks
- `notebooks/` – one notebook for each pipeline stage
- `figures/` – charts saved as PNG files
- `model/` – saved joblib pipeline
- `reports/` – technical report and presentation

## How to run
1. Install the packages listed in `requirements.txt`
2. Open the notebooks in order (01 → 07)
3. Each notebook saves its output for the next notebook to use.

## Dataset
World Food Programme – Uganda Food Prices (retail, KG, white maize, and beans)
